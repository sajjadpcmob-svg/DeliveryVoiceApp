# اپلیکیشن پخش و توزیع (نسخهٔ اندروید با شمارش صوتی آفلاین)

این پروژه اپ وبی شما را به یک اپلیکیشن واقعی اندروید (APK) تبدیل می‌کند که شمارش صوتی آن **به صورت پیوسته و آفلاین فارسی** کار می‌کند — بدون قطع شدن، بدون صدای دینگ‌دینگ، و بدون نیاز به اینترنت برای تشخیص صدا.

## ساخت APK روی GitHub (خیلی ساده)

1. یک مخزن (repository) جدید در GitHub بسازید.
2. همهٔ فایل‌های این پروژه را در آن آپلود (push) کنید.
3. به تب **Actions** بروید — ساخت به صورت خودکار شروع می‌شود.
4. چند دقیقه صبر کنید تا تیک سبز بیاید.
5. روی آخرین اجرا کلیک کنید و در بخش **Artifacts** فایل `DeliveryVoiceApp-debug-apk` را دانلود کنید.
6. فایل APK را روی گوشی نصب کنید (نصب از منابع ناشناس را فعال کنید).

مدل فارسی (حدود ۴۷ مگابایت) در زمان ساخت به صورت خودکار دانلود و داخل APK قرار می‌گیرد؛ لازم نیست کاری انجام دهید.

## نحوهٔ استفاده
- دکمهٔ شمارش صوتی را نگه دارید و صحبت کنید؛ تا وقتی نگه داشته‌اید گوش می‌دهد.
- دفعهٔ اول اجازهٔ میکروفون را بدهید.
